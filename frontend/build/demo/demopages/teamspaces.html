Architecture Decision Record (ADR-042): Yjs CRDT vs OT

Status: Approved · Created by Jane Doe ·

Context & Problem Statement:
AHI requires real-time offline-first collaborative text editing for notes, code mode sessions, and teamspace document trees. Centralized conflict resolution introduces server latency and breaking offline sync.

Decision Drivers:
• Offline-first local SQLite commits.
• Zero conflict merge spikes across concurrent desktop clients.
• Low memory overhead in Electron 34+ main/renderer IPC bridge.

Chosen Option: Yjs CRDT with WebSocket Relay:
